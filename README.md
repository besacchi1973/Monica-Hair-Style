# Monica Hair Style - Professional Salon Management App

🇮🇹 **Applicazione Moderna per la Gestione Completa di Saloni di Parrucchiera**

## 📋 Caratteristiche Principali

✅ **Dashboard** - Statistiche in tempo reale
✅ **Gestione Clienti** - CRUD completo con storico
✅ **Agenda Appuntamenti** - Gestione professionale
✅ **Gestione Servizi** - Catalogo completo
✅ **Gestione Staff** - Operatori e commissioni
✅ **Cassa e Incassi** - Metodi pagamento
✅ **Report e Statistiche** - Analisi complete
✅ **Design Responsivo** - Mobile, Tablet, Desktop
✅ **UI Professionale** - Colori neutri e raffinati

## 🚀 Installazione Veloce

### Windows
```bash
install.bat
```

### macOS/Linux
```bash
chmod +x install.sh
./install.sh
```

## 📱 Utilizzo

1. Configura `.env.local` con il tuo MongoDB URI
2. Esegui: `npm run dev`
3. Accedi a: http://localhost:5173
